# 需求说明（最强蜗牛攻略智能体）

> 状态：2026-09-08 初稿，待业务方确认。Demo 阶段实现范围见「六、Demo 范围」。

## 一、业务背景（产品/业务层）

「最强蜗牛」（青瓷游戏，放置/收集/养成 RPG）攻略题材庞杂，玩家在聊天里高频提问求助（新手怎么玩、贵重品怎么选、装备怎么合成、某个密令是什么、某地图怎么推等）。本智能体把全套攻略内容统一建库，提供智能问答（RAG），回答时附引用来源，帮助玩家与运营快速找到准确答案。

## 二、核心能力：智能问答（RAG）

### 2.1 攻略知识问答
- 支持对「最强蜗牛」全套攻略内容提问，例如：
  - "新手前期刷哪个图收益最高？"
  - "贵重品怎么选？开服思路推荐？"
  - "这周是抽奖周，气球大作战怎么打？"
  - "XX 密令是什么？"
  - "货币怎么获取和使用？"
  - "希域/天竺/时空孔隙怎么玩？"
- **回答必须附引用来源**：来源文件 + 章节/标题 + 原片段，供玩家核对。
- 知识库中没有的内容，明确说明"知识库内未找到相关信息"，不编造。

### 2.2 知识库
- 支持 PDF / Word / Excel / PPT / HTML / 图片 / 纯文本多种格式攻略原料。
- 检索采用**轻量混检**（D4 已定）：SQLite 向量近似 + FTS5 关键词/BM25，无需外部向量库。
- 建库脚本（scripts/build_kb.py）解析 `knowledge/raw/` 下的材料，构建并落盘 SQLite 知识库。

### 2.3 首期建库内容（用户确认：全套攻略）
- 新手入门与系统解析：新手指南、贵重品/装备/货币、五围与面板、基因/形态、探索地图等
- 进阶玩法：物种战争、神龙许愿、杀手、时空孔隙、各国家/地图攻略
- 资料速查：密令、兑换码、装备合成表等可结构化内容

### 2.4 多模态 / 文档解析能力（核心增强，2026-09-08 澄清）
> 智能体需要具备**直接看网页、文档、图片、文本并解析内容**的能力。两种使用场景**都要**：

- **场景 A｜对话中直接解析**：用户可在聊天页上传图片/文档，或粘贴网页链接/文本，智能体解析内容后结合知识库回答。例如：
  - 发一张装备/贵重品截图问"这个怎么培养？"
  - 发一个攻略网页链接问"这篇里面密令是什么？"
  - 上传一份攻略 Word/PDF 问"里面推荐的开局思路？"
  - 直接粘贴一段文本问"这说的是哪个玩法？"
- **场景 B｜建库时批量解析**：建库阶段把网页、图片、文档作为原材料自动解析收录进知识库（如批量抓取攻略页、批量 OCR 攻略截图）。

#### 图片内容解析（双通道，按需切换，D9）
- **多模态大模型通道**：用 qwen-vl 直接看懂图片并提取语义信息，适合对话中理解用户截图、需要"看懂内容"的场景。
- **离线 OCR 通道**：用 PaddleOCR 本地批量提取图片文字，适合建库时大量截图文字化，离线可跑。
- 通道选择策略：对话中对单张/少量图用多模；批量建库图片优先用离线 OCR。

#### 网页 / 文档 / 文本解析（D10）
- **网页**：抓取 HTML → 提取正文（去导航/广告）→ 转纯文本。
- **PDF**：PyMuPDF + pdfplumber（正文+表格）。
- **Word**：python-docx；**Excel**：openpyxl/pandas（含多 sheet）；**PPT**：python-pptx。
- **纯文本**：直接读取；**图片**：走图片双通道。

### 2.5 分类标签（多标签，2026-09-08 确认）
> 用户在聊天页提问时，可以**同时命中多个分类标签**（例如"新手刷哪个图"同时属于「新手入门」和「探索地图」）。因此标签采用**多标签**设计，一条攻略内容可挂多个标签，一个提问可匹配多个标签。

- **标签体系（初版）**：
  - 新手入门 / 系统解析（贵重品、装备、货币、基因、形态、五围）
  - 探索地图（各国/地图/时空孔隙）
  - 周活动（抽奖周/许愿周/供奉周及大作战）
  - 资料速查（密令、兑换码、合成表）
  - 进阶玩法（物种战争、神龙许愿、杀手等）
- **多标签语义**：
  - 建库时一条内容可打**多个标签**（如「贵重品怎么选」的内容同时标 `新手入门` + `系统解析`）；
  - 聊天页提问时可按**多个标签**过滤（如选「新手入门」+「探索地图」），选取任一标签命中即可；检索结果也保留标签用于分类展示；
  - 标签体系可在管理后台维护（增删标签、给条目重新打标）。

## 三、聊天网页

- 单页 Web（原生 fetch + SSE），支持流式回答、来源展示。
- 支持按攻略分类（如新手/探索/周活动/密令）入口，**支持多选标签过滤**（一件事可属多个标签）。
- **支持上传图片/文档、粘贴网页链接/文本**（2.4 场景 A），解析后纳入问答上下文。

## 四、管理后台（用户确认：需要，随功能阶段配套）

独立 `/admin` 页面，管理 API 前缀 `/api/admin/*`。模块随功能阶段配套：

1. **知识库管理**：攻略文档上传（PDF/Word/Excel/PPT/HTML/图片）、条目列表/删除/统计、触发重建索引、**标签管理（增删标签、给条目打多个标签）**。
2. **系统运维**：服务/LLM 状态（/api/health）、最近日志查看、解析/OCR 任务状态。
3. **模型管理**：LLM/Embedding 配置（base_url / 模型名 / Key 状态检测）、测试对话。

> 预测记录、数据源等模块本游戏类智能体不涉及；若后续需要可扩展。

## 五、验收标准（可衡量）

1. 建库脚本能解析 `knowledge/raw/` 下至少 1 份 PDF 与 1 份纯文本并建库成功，入库后可统计条数。
2. 对知识库内已有内容提问，能返回引用来源且来源文件正确。
3. 对知识库外的问题，能明确回答"未找到"，不编造。
4. `/api/health` 返回 service=up；无 Key 时 llm 状态如实反映未配置。
5. 聊天页能完成一次提问并流式展示回答与来源。
6. 管理后台知识库页能列出条目并触发重建。
7. 离线冒烟测试（不依赖 API Key）通过。
8. **对话解析**：上传一张含文字的图片，智能体能解析文字并结合知识库回答；粘贴一个网页链接，能提取正文。
9. **建库解析**：图片经 OCR、网页经正文抽取后均能入库并被检索命中。
10. **多标签**：一条内容可挂多个标签；按多标签过滤提问时，任一标签命中即返回；管理后台可维护标签。
